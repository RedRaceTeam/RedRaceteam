### ⭐ Наш главный проект

<div align="center">

# 🏎️ INDY Leader Bot

**[Активный]**

Бот для фанатов IndyCar, который даёт актуальную информацию о гонках, пилотах и результатах.

</div>

#### 📌 Возможности бота
- 📊 **Статистика пилотов** — позиции, очки, победы
- 🏁 **Календарь гонок** — расписание сезона
- 🔔 **Уведомления** о старте гонок и изменениях в таблице
- 📈 **Текущий рейтинг** лидеров чемпионата
- 🤖 **Простой и быстрый интерфейс** в Telegram
